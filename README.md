# Mantenimiento Técnico - Cámara Frigorífica

Página web de guía técnica y mantenimiento preventivo para cámaras frigoríficas. Incluye especificaciones de seguridad, inspección de componentes, calendario de rutinas y registro de fallas.

## Características
- Soporte bilingüe: Español (ES) e Inglés (EN).
- Visualización interactiva y responsive de componentes y tareas de mantenimiento.

## Uso local
Para abrir la aplicación de manera local:
1. Hacer doble clic en el archivo `index.html` (o abrirlo con cualquier navegador web).
